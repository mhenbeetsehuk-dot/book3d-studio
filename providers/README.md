# Provider adapters

Planned adapters are intentionally isolated here:
- `meshy.py`: text/image-to-3D, rigging and animation.
- `deepmotion.py`: video-to-motion and motion retargeting.
- `voice.py`: narration/dialogue speech generation.
- `llm.py`: stronger book analysis, story bible, shot design and continuity checking.

The app core must remain usable without any provider account.
