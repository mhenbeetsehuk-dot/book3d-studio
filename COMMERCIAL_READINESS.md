# Commercial readiness notes

Book3D Studio is currently a single-user local prototype. The architecture should preserve an upgrade path to multi-user deployment, provider abstraction, usage metering, cloud rendering, billing, project storage, security controls and auditability.

Do not commit API keys, user manuscripts, generated private assets, or third-party model files whose licences do not permit redistribution/commercial use. Provider adapters must document commercial-use terms before production launch.

No open-source licence is granted by this prototype package. Before public distribution, choose and add an appropriate licence with legal review.
